How Community Criticality Works

When multiple hostelers in the same hostel report facing the same problem, the ticket’s effective priority is automatically raised. Each threshold below triggers a priority bump or forces an immediate Urgent status, recalculating the SLA deadline from the time current level began.

Never lowers below base: Staff-assigned base priority is always preserved.
Idempotent & safe: Repost undos dynamically recalculate effective priority.
